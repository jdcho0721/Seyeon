# 세연(洗然): 사유의 손길, 눈에 보이는 소리

**세연정과 오우가 사운드스케이프 — Humartology**

고산 윤선도의 보길도 세연정 원림과 〈오우가〉의 다섯 벗 — 물·바위·소나무·대나무·달 — 을 소리와 영상, 해설로 만나는 다감각 인터랙티브 작품입니다. 관람객은 정원 그림 곳곳을 눌러 소리를 깨우고, 세 단계(① 조우 → ② 창조 → ③ 개척)를 거쳐 자기만의 '세연의 길'을 완성합니다.

스크린 리더 없이도 **터치·마우스·스와이프만으로** 모든 기능을 쓸 수 있도록, 큰 버튼과 실시간 자막, 눈에 보이는 위치 표시를 갖추었습니다.

- 작가: 조준동 (성균관대학교 정보통신대학 명예교수)
- 협찬: 김호용 ((주) 위프코 대표), 육근해 (장애인문화복지연구소 대표)
- 제작: 2026년 5월

## 3. 작품 구성 — 세 단계

| 단계 | 하는 일 | 끝나면 |
|---|---|---|
| **① 조우(遭遇)** | 정원을 자유롭게 눌러 열 곳의 소리·영상·해설을 만남 | 다섯 벗(물·바위·소나무·대나무·달)을 모두 들으면 〈오우가〉 낭송 |
| **② 창조(創造)** | 네 가지 미션 중 하나를 골라 지정된 세 벗의 기운을 모음 | 완성 영상 → 상장 음성 해설 → 시 낭독 |
| **③ 개척(開拓)** | 다섯 벗 중 1~5가지를 골라 이름을 붙이고, 직접 찾아 모음 | 개척의 상 |

**2단계 미션**

| 미션 | 모을 대상 | 상장 |
|---|---|---|
| 덕의 정원 (Resonance) | 혹약암·사투암·소나무 | 공명(共鳴)의 상 |
| 정화의 물결 (Purity) | 혹약암·사투암·물 | 투명(透明)의 상 |
| 무(無)의 공간 (Serenity) | 소나무·대나무·물 | 일체(一體)의 상 |
| 합일의 풍경 (Harmony) | 달빛·물·물 위의 달 | 해방(解放)의 상 |

## 4. 관람 방법

**기본 조작**

| 하고 싶은 것 | 방법 |
|---|---|
| 단계 이동 | 화면 아래 **① 조우 ② 창조 ③ 개척** 버튼, 또는 화면을 **좌우로 밀기** |
| 소리 듣기 | 정원 그림을 누르기. 정확히 맞추지 않아도 **가장 가까운 곳**이 반응 |
| 바로 듣기 | 화면 아래 벗 버튼 줄(소나무·대나무·물…)을 누르기. 옆으로 밀면 더 있음 |
| 위치 확인 | **◎ 위치 보기** — 그림 위에 각 벗의 위치를 표시. 세로 화면에서 잘린 곳은 가장자리에 `◀ 소나무` 처럼 방향 표시 |
| 자세한 해설 | 자막의 **📖 자세한 해설 듣기**, 같은 버튼을 한 번 더, 또는 그림을 빠르게 두 번 누르기 |
| 영상 보는 중 | **좌우로 밀기** = 다음·이전 벗 / **한 번 누르기**·**아래로 밀기** = 닫기 |
| 미션 다시 고르기 | 2단계에서 **🎯 미션 고르기** |
| 가로로 크게 보기 | 오른쪽 아래 **⛶** 버튼 (다시 누르면 원래대로) |
| 작품 정보·사용법 | 오른쪽 위 **ⓘ 안내** — 마우스를 올리면 잠시 뒤 자동으로 열림 |
| 도슨트 챗봇 | 오른쪽 위 **💬** — "소나무", "진동", "철학" 같은 낱말로 질문 |
| 키보드 | `←` `→` 단계·벗 이동, `Esc` 창·영상 닫기 |

**미션 집중 모드**

미션을 고르면 "영역을 터치하여 기운을 모으십시오" 안내가 나옵니다. 그다음 화면을 한 번 누르면 **집중 모드**로 바뀌어,

- 배경 그림과 **반짝이는 대상 서클**만 남고 나머지 버튼은 모두 사라집니다.
- 서클을 누르면 그 벗이 재생되고, 모은 서클은 색이 채워집니다. 위쪽 게이지에 `1 / 3 모음` 처럼 진행이 표시됩니다.
- 다 모으면 자동으로 원래 화면으로 돌아옵니다. 도중에 버튼을 다시 보려면 화면을 좌우로 밀거나 `Esc`를 누르세요.

**상장**

미션을 마치면 상장이 뜨고 제목·수여 문구·날짜를 **음성으로 읽어 줍니다**. 이어서 시 한 구절이 낭독됩니다. **🔊 상장 다시 듣기**로 다시 들을 수 있습니다.

## 5. 접근성 설계

**스크린 리더 대신 보이는 자막**
- 모든 음성 안내를 화면 아래 자막 바에 동시에 표시
- 자막은 세로 화면 3줄, 가로 화면 2줄 높이로 제한해 배경을 덜 가림. 길면 자막 안을 위아래로 밀어 읽고, 아래쪽이 흐려지며 "↕ 밀어서 더 보기"가 표시됨
- **▾ 접기** 로 한 줄만 남기고, **✕ 닫기** 로 감춤

**누르기 쉽게 (Fitts의 법칙)**
- 모든 버튼 최소 44~48px, 단계 버튼 56px
- 그림 어디를 눌러도 가장 가까운 영역이 반응하고, 누른 자리에 잔물결과 이름표 표시
- 더블탭 확대 지연을 없애 즉시 반응 (두 손가락 확대는 그대로 가능)

**지금 어디에 있는지 보이게**
- 현재 단계 버튼은 단계 색(조우 청록 · 창조 금빛 · 개척 보라)으로 채워지고 위쪽 막대 표시
- 단계를 옮기면 화면 가운데에 단계 이름이 잠깐 나타남
- 재생 중인 벗 버튼은 색으로 채워지고, 미션 대상은 테두리 강조, 모은 것은 ✓

**화면 방향**
- 세로: 하단 단계 버튼 + 벗 버튼 줄
- 가로(휴대폰): 단계 버튼이 왼쪽 세로 레일로 이동, 3단계 화면은 좌우 2단 배치
- **⛶ 가로 보기:** 세로로 든 휴대폰에서는 화면 자체를 90° 돌려 가로로 보여 줌. 브라우저 전체화면 기능을 쓰지 않으므로 "전체화면을 종료하려면…" 안내가 뜨지 않음
- 아이폰 노치·홈 표시줄 영역(safe area) 대응

**그 밖에**
- 진동: 벗마다 다른 진동 패턴 (진동을 지원하는 안드로이드 기기)
- "동작 줄이기" 설정 시 애니메이션 최소화, 고대비 모드 지원

## 6. 내용 수정하기

모든 설정은 `index.html` 안에 있습니다.

**영역 위치·영상·해설 문구** — `Garden.elements`

```js
pine: {
    x: [0, 0.4], y: [0.3, 0.6],        // 세연정.png 안의 위치 (가로·세로 비율 0~1)
    file: 'Boughs_of_Deep_Timber.mp4',
    content: "...",                    // 누르면 읽는 해설
    detail: "..."                      // 자세한 해설
}
```

좌표는 **배경 그림 기준**이라 화면 크기나 방향이 달라도 같은 자리를 가리킵니다. 배경 그림을 바꾸면 이 값을 맞춰 주세요.

| 바꿀 것 | 위치 |
|---|---|
| 이어지는 시 구절 (자세한 해설 끝) | `EkphrasisData` |
| 미션 대상·완성 영상·안내 문구 | `ResonanceModule`, `PurityModule`, `HarmonyModule`, `HoneyModule` |
| 미션 완성 후 시 낭독 | `Ekphrasis.poems` |
| 상장 제목·문구 | `certData` |
| 3단계 조합별 길 이름 | `pioneerCombos` |
| 벗 버튼 이름·아이콘·순서 | `mobile-ux-js` 스크립트의 `FRIENDS` |
| 진동 패턴 | `Garden.hapticMap` |
| 챗봇 답변 | `responses` |

**모바일·접근성 기능**은 `<style id="mobile-ux-css">` 와 `<script id="mobile-ux-js">` 에 모아 두었습니다. 원래 작품 코드는 되도록 그대로 두고 덧붙이는 방식입니다.

## 8. 알아 두면 좋은 점

- **소리가 안 날 때:** 휴대폰 무음(진동) 모드에서는 브라우저가 소리를 막을 수 있습니다. 브라우저 정책상 **화면을 한 번 누른 뒤부터** 소리가 납니다.
- **음성합성:** 한국어 음성이 설치된 기기에서 읽어 줍니다. 기기·브라우저마다 목소리가 다릅니다.
- **가로 보기:** 화면을 CSS로 돌리는 방식이라 주소창은 그대로 남습니다. 기기를 실제로 가로로 돌리면 회전은 자동으로 풀리고 가로 배치만 유지됩니다.
- **해설이 끝나면** 전체화면 영상은 자동으로 닫힙니다.
